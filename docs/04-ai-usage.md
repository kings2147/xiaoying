# 全仓库 AI 使用与贡献

AI 辅助范围：读取用户指定的题目、提炼需求、设计、编写实现/测试/文档、执行测试、生成示例记录、创建 commit 并推送仓库。
运行时模型：按用户选择调用本机已登录 Codex CLI，逐轮决定业务工具动作；合成工具结果由 Python 产生和校验。
用户已发生的贡献：提供试题与仓库、指定四题顺序、强调工程步骤和 commit、选择真实模型入口。尚未有用户独立修改代码或人工复核的记录。
本记录不把 AI 生成代码描述为本人独立手写，也不虚构人工修改比例。提交人应在实际运行、理解、修改后更新相应记录。
每题具体范围见 task1–task4 的 04-ai-usage.md。模型与离线替身的运行证据明确区分，所有业务数据为合成数据。
