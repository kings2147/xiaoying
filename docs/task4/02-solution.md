# 第四题：方案

模型先 search_materials，再 draft_script；每个镜头指定 source_id、fact_id、visual、transition_id、hold_seconds。
事实旁白只能来自检索结果；转场和镜头动作来自品牌允许清单。标题限于用户主题及功能演示后缀，检查器拒绝无来源数字与禁用表述。
这种结构让事实来源可逐镜头回查，也保留了模型对镜头顺序、删减、停留和转场的编排决策。自由发挥的旁白不在本次范围内。
estimate_duration 使用每秒 4 字的合成语速，加上各镜头停留时间；场景时长求和得到总时长。
check_rules 校验当前草稿；重写草稿立即清空旧检查，要求同一版本同时通过时长与规则检查才返回 completed。
模型可在观察超时长后删减镜头、转场或停留并重验；不能满足时返回 incomplete。保留前一版及其实际检查结果。
语速只是可复现估算，真实配音的时长需要实测。品牌清单和结构化事实不是一般语义真实性判定器。
