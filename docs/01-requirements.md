# 全仓库需求与评审入口

按用户要求依次实现试卷中的四道项目题，保留各题独立工程提交与证据。
每题均提供 CLI、模型驱动的有界工具循环、合成业务数据、正常/资料不足/工具失败场景和真实模型运行记录。

| 题号 | 业务与主要成功标准 | 详细需求 |
|---|---|---|
| 1 | 审核后排期、冲突建议与确认边界、幂等草稿和明确保存失败 | [第一题](task1/01-requirements.md) |
| 2 | 预算与截止时间内规划、动态重规划、失败结果保留、续跑 | [第二题](task2/01-requirements.md) |
| 3 | 原文支持、完整引用、冲突披露、资料外停止、上下文追问 | [第三题](task3/01-requirements.md) |
| 4 | 有事实来源的分镜、可复现时长估算、超时修订后重验 | [第四题](task4/01-requirements.md) |

共同边界：不连接真实发布、付费执行或企业私有系统；资料全部合成。模型离线时可用 Mock，真实决策验证以 Codex 记录为准。
