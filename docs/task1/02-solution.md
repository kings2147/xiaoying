# 第一题：方案

模型每轮读取请求、工具目录及历史结果，返回一个 JSON 动作。Python 校验工具名/参数后执行工具，再把真实结果送入下一轮。
工具：read_material → check_rules → query_slots → propose_slot → save_draft；调用顺序由模型选择，工具自身验证前置状态。
正常与冲突请求得到不同 query_slots 结果，模型据此选择原时段或替代时段。
程序独立计算硬性变更是否已获得精确时段批准；模型无法通过参数伪造批准。

SQLite 使用 (kind, request_id) 唯一主键；重复相同草稿返回原 ID，改变内容复用 ID 返回冲突。
成功状态来自保存返回，不采信模型声称的成功。时段比较统一为时间戳，避免时区写法绕开冲突。
最多 16 轮（可配置 1–64），到上限返回 incomplete，并保留已有结果。
原生实现减少框架依赖，标准库测试覆盖约束；规则检查为合成业务规则，不声称具备真实视觉审核能力。
