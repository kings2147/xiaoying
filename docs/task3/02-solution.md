# 第三题：方案

模型动态选择 search_documents、read_document 和 answer_from_sources；完整原文读取是回答的前置条件。
检索使用中文二元词组与少量同义词归一化；上下文追问由模型结合此前用户问题选择查询。
检索结果只暴露文档标题、日期与得分；读取工具返回原文与事实索引。模型可补查或改写查询。
回答工具要求所有检索到的候选文档都已读取并列入引用，避免只读一篇就忽略已知冲突。
结构化事实索引的每个值必须出现在原文中；不一致时拒绝使用并返回资料读取失败。
同一事实字段多值时返回 conflict，列出双方原文和版本日期，请求适用范围/优先级；不以日期自动覆盖。
最终回答由真实读出的原文构造，因此引用可直接回查。模型负责查询、读取和停止的动作选择。
限制：事实字段需维护；全文词法检索可能产生无关候选，当前策略保守披露全部候选；暂未实现一般自然语言矛盾识别或任意多跳推理。
