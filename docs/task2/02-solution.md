# 第二题：方案

工具提供素材检索、计划估价、脚本生成与方案保存。模型观察候选方案估价后自行选择下一方案。
premium 为 12 单位/90 分钟，lean 为 8 单位/45 分钟，basic 为 5 单位/30 分钟；总价由明细相加，截止时间由开始时间加耗时计算。
生成与保存工具强制要求该方案已估算且同时满足预算和截止时间；模型无法绕过这两个条件。
已成功的素材、估算、脚本写入独立的可更新 checkpoint；最终交付物使用不可变幂等主键。
检查点键包括完整业务输入的哈希（排除故障注入参数），修改预算/截止时间会建立新的检查点。
重启时恢复成功步骤，模型可以继续失败步骤；请求 ID 相同但保存内容变化会拒绝覆盖。
幂等写入使用事务内 INSERT OR IGNORE 再读回，8 路并发重复提交测试验证仅一份新结果，其余返回同一 ID。
脚本生成工具使用合成模板，这里的模型能力考核重点是依赖、状态与动态重规划。
